# Validation - Overview Tab

## Verification Steps
1. **Layout Consistency**: Ensure the sidebar stays on the left on desktop and the grid is correctly aligned.
2. **Social Links**: Verify that the LinkedIn and GitHub links open in new tabs and have the correct icons.
3. **Card Styling**: Verify that the pinned repo cards have the correct border, padding, and color scheme.
4. **Responsiveness**: 
   - Check that at <768px the sidebar moves above the projects.
   - Check that repo cards stack vertically on small screens.
5. **Image Rendering**: Ensure the large avatar is crisp and circular.
