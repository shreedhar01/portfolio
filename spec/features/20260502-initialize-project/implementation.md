# Implementation - Initialize Project

## Steps
1. Create `src/css` and `src/js` directories.
2. Create `assets/images` and `assets/fonts` directories.
3. Create `index.html` in the root directory.
4. Create `src/css/style.css` for global styles.
5. Create `src/js/app.js` for main logic.
6. Link CSS and JS in `index.html`.

## Code Snippets
### index.html
```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Portfolio</title>
    <link rel="stylesheet" href="src/css/style.css">
</head>
<body>
    <script src="src/js/app.js"></script>
</body>
</html>
```
