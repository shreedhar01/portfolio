# Specification - Initialize Project

## Goal
Establish the foundational project structure and boilerplate for the personal portfolio website.

## Requirements
- Create a clear directory structure for source code and assets.
- Initialize a base `index.html` with necessary meta tags.
- Create a base `style.css` for global styles.
- Create a base `app.js` for interactivity.
- Ensure all files are correctly linked.

## Structure
- `src/`: Core logic and structure.
  - `src/css/`: Stylesheets.
  - `src/js/`: JavaScript files.
- `assets/`: Static resources.
  - `assets/images/`: Images and icons.
  - `assets/fonts/`: Custom fonts (if any).
- `index.html`: Root entry point.
