# Specification - Header

## Goal
Create a navigation header that mirrors the GitHub top navigation bar aesthetic no need to be functional.

## Requirements
- Sticky/Fixed position at the top of the page.
- Dark theme (standard GitHub header style).
- Logo placeholder (left-aligned).
- Navigation links: "Projects", "Skills", "About", "Contact".
- Mock search bar.
- Responsive design: Links should ideally collapse or scroll on smaller screens.

## Components
- `header`: Main container.
- `.header-item`: Individual items within the header (links, logo, search).
- `.search-bar`: Input field for the mocked search.
