# Validation - Header

## Verification Steps
1. **Visual Match**: Compare the header against GitHub's header for color consistency (#24292f).
2. **Sticky Behavior**: Ensure the header stays at the top when scrolling (once content is added).
3. **Link Interaction**: Verify that links change color or state on hover.
4. **Responsiveness**: Check that the header doesn't break on narrow viewports.
5. **DOM Check**: Verify the header exists as the first child of `<body>` or within the `#app` container.
