# Shreedhar Kala Magar — Portfolio

[shreedhar.dev](https://shreedhar.dev) showcases Shreedhar’s full-stack mobile work, ShroudChat, and open-source contributions.

The site uses static HTML, CSS, and JavaScript. Open `index.html` directly in a browser. GitHub Pages serves the repository root, and `CNAME` configures the custom domain.

- `index.html` contains the page’s content, links, and search and social metadata.
- `src/css/style.css` defines the responsive layouts and light and dark themes.
- `src/js/app.js` applies the device’s color preference and remembers theme changes in the browser.
- `assets/images/` holds the portrait, ShroudChat store screenshots, favicons, and social sharing image.
